Настоящая Политика регулирует обработку и защиту информации, которую Пользователь передаёт при использовании сайта и приложения PurrGame (далее — «Сервис»), владелец — Администрация проекта PurrGame (далее — «Администрация»).1.1. This Policy governs how information that the User provides while using the PurrGame website and app (the “Service”) is processed and protected. The Service is operated by the PurrGame project administration (the “Administration”).

1.2. Используя Сервис, Пользователь соглашается с Политикой. Если он не согласен, он обязан прекратить использование Сервиса.1.2. By using the Service the User agrees to this Policy. If the User disagrees, they must stop using the Service.

2. Какие данные собираются2. Data we collect

2.1. Идентификаторы аккаунта; техническая информация (IP-адрес, данные о браузере, устройстве и операционной системе); история взаимодействий с Сервисом; сведения о подписке (тариф, даты). Данные банковской карты Администрация не получает и не хранит — платёж проходит на стороне платёжного сервиса.2.1. Account identifiers; technical information (IP address, browser, device and operating system data); interaction history with the Service; subscription details (plan, dates). The Administration does not receive or store bank card data — payments are handled by the payment service.

2.2. Паспортные данные, документы и фотографии Сервис не запрашивает.2.2. The Service does not ask for passport data, documents or photos.

3.1. Обеспечение работы функционала и подписки; связь с Пользователем и поддержка; анализ и улучшение Сервиса.3.1. Operating the features and the subscription; contacting the User and providing support; analyzing and improving the Service.

4.1.
